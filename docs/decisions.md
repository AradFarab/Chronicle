# تصمیم‌های پروژه نرم‌افزار حضور و غیاب

همه تصمیم‌ها با آراد در ۱۴ مهر ۱۴۰۵ گرفته شده‌اند. سند کامل طراحی: `docs/design-doc.md`.

## ساختار و فناوری

| موضوع | تصمیم |
| --- | --- |
| پایه | Frappe Framework نسخه ۱۶؛ فریم‌ورک فورک نمی‌شود |
| تعداد اپ | یک اپ (نام کاری hozur)؛ تقویم شمسی ماژول جدا نیست |
| Frappe HR | نصب نمی‌شود (به ERPNext وابسته است)؛ فقط از کدش الگو گرفته می‌شود |
| موبایل | فقط PWA؛ اپ بومی ساخته نمی‌شود |
| زبان | Python و Frappe در بک‌اند؛ Vue 3، TypeScript، frappe-ui و Tailwind در رابط |
| رابط | اولویت با رابط زیبا و ساده؛ فارسی و RTL از پایه |
| روش توسعه | وایب‌کد با Claude Code |
| لایسنس | GPLv3، متن‌باز |
| نام نهایی | بعداً تصمیم گرفته می‌شود |

## استقرار، دستگاه و داده

| موضوع | تصمیم |
| --- | --- |
| استقرار | روی سرور هر شرکت؛ از بیرون شرکت هم در دسترس |
| دستگاه فعلی | ZKTeco، احتمالاً مدل VF600 |
| تعریف دستگاه | از داخل PWA (IP، پورت، رمز، شعبه)؛ بدون تغییر کد |
| پالیز | دستگاه فعلاً به پالیز وصل است و پالیز لاگ را پاک نمی‌کند؛ ماه آزمایشی موازی با پالیز |
| سابقه قدیمی | ورود از فایل اکسل خروجی پالیز |
| کد بیمه | یک کد برای مبلمان، کافه و اکسسوری؛ کارگاه جدا لازم نیست |
